# Project instructions

- Preserve working gameplay and tuned settings unless the requested
  change requires adjusting them. Avoid unrelated changes.

- Prioritize smooth frame rates on the target hardware.
  Consider performance and memory costs when adding effects or assets.

- Keep menus clear and readable. Remove unnecessary text while
  preserving useful control instructions and accessibility information.

- Follow the existing project structure and build process.
  Avoid adding dependencies unless they are needed.

- Run available build checks after code changes. Clearly state what
  was verified and what still needs testing on the target hardware.

- Update the existing handoff after significant changes. Record what
  changed, lessons learned, known issues, and the next steps.
